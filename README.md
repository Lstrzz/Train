# Train

Приложение для планирования тренировок в зале и дома. Упражнения, тренировки с подходами
и отдыхом, план на неделю, запуск тренировки с таймером отдыха и история с графиками
прогресса. Все данные хранятся на телефоне: без аккаунтов, регистрации и облака.

## Возможности

- **Упражнения.** Создание, описание и редактирование. Для каждого упражнения есть график прогресса.
- **Тренировки.** Несколько упражнений, у каждого свои подходы. В подходе задаются повторения или время, а также отдых после него.
- **Суперсеты.** Два упражнения чередуются без отдыха между ними, например A1 → B1 → отдых → A2 → B2.
- **План на неделю.** Тренировки распределяются по дням недели.
- **Запуск тренировки.** Отметка подхода, таймер отдыха со звуком и вибрацией. Фактические повторения сохраняются в тренировку, поэтому в следующий раз стартовое значение будет таким же.
- **История.** Список выполненных тренировок и количество подходов.
- **Данные.** Экспорт всех данных в JSON-файл, импорт из файла и полная очистка.

> Таймер отдыха работает, пока приложение открыто.

## Скачать

Готовый APK для Android лежит в разделе [Releases](https://github.com/Lstrzz/Train/releases/latest).
Откройте файл на телефоне и установите приложение. Может понадобиться разрешить установку
из браузера или файлового менеджера.

## Запуск из исходников

Нужны Node.js (актуальный LTS) и приложение [Expo Go](https://expo.dev/go) на телефоне.

```bash
npm install
npx expo start -c
```

Отсканируйте QR-код в терминале камерой телефона или в Expo Go. Телефон и компьютер
должны быть в одной сети Wi‑Fi.

## Сборка APK

Сборка выполняется в облаке [EAS](https://docs.expo.dev/build/introduction/). Нужен аккаунт Expo.

```bash
npx eas-cli@latest login
npx eas-cli@latest build -p android --profile preview
```

Профили описаны в `eas.json`: `preview` собирает APK для установки, `production` — AAB для Google Play.

## Стек

- [Expo](https://expo.dev) SDK 58 и React Native
- [Expo Router](https://docs.expo.dev/router/introduction/) для навигации
- `@react-native-async-storage/async-storage` для локального хранения
- `expo-audio` и `expo-haptics` для звука и вибрации таймера
- `expo-linear-gradient`, `expo-file-system`, `expo-sharing`, `expo-document-picker` для интерфейса и резервных копий

## Структура проекта

```
src/
  app/          экраны (Expo Router): вкладки, редакторы, запуск тренировки, данные
  components/   общие компоненты и окно выбора значений
  constants/    палитра и утилиты дат
  lib/          хранилище, типы и логика тренировок
assets/         иконки и звук таймера
eas.json        профили сборки EAS
app.json        конфигурация приложения
```

## Данные и резервные копии

Все данные хранятся в AsyncStorage под ключом `train:v1`. На экране «Данные» можно:

- **экспортировать** все данные в файл `train-backup-ГГГГ-ММ-ДД.json`;
- **импортировать** файл, заменив текущие данные;
- **стереть** все данные.

Формат файла описан в `src/lib/store.tsx` (функция `parseBackup`). Импорт проверяет структуру
и отклоняет файлы, которые не похожи на резервную копию Train.

## Релиз

1. Обновите `version` в `app.json` и `versionCode` в `android` при необходимости.
2. Соберите APK командой из раздела «Сборка APK».
3. Создайте релиз на GitHub, загрузите APK как ассет и опишите изменения.
